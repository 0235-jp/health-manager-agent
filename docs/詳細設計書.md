### 1.2 API詳細仕様

#### 1.2.1 ヘルスデータ API

**GET /api/health-data**

クエリパラメータ:
| パラメータ | 型 | 必須 | 説明 |
|-----------|------|------|------|
| data_type | string | - | データタイプでフィルタ |
| source | string | - | ソースでフィルタ |
| start_date | ISO8601 | - | 開始日時 |
| end_date | ISO8601 | - | 終了日時 |
| limit | number | - | 取得件数（デフォルト: 100） |
| offset | number | - | オフセット |

レスポンス:
```json
{
  "data": [
    {
      "id": 1,
      "data_type": "weight",
      "value": 70.5,
      "unit": "kg",
      "source": "manual",
      "recorded_at": "2026-01-10T08:00:00Z",
      "created_at": "2026-01-10T08:05:00Z"
    }
  ],
  "pagination": {
    "total": 150,
    "limit": 100,
    "offset": 0
  }
}
```

### 1.3 統一プラグインシステム詳細

#### 1.3.1 アーキテクチャ概要

3種類のプラグイン（DataSource, Agent, Notification）を統一的に管理するシステム。

```
                        +------------------+
                        |  PluginManager   |
                        |  (Singleton)     |
                        +--------+---------+
                                 │
                  +--------------+---------------+
                  │              │               │
        +---------▼----+ +-------▼-------+ +----▼---------+
        | PluginLoader | | PluginRegistry| |   EventBus   |
        +--------------+ +---------------+ +--------------+
```

#### 1.3.2 基底インターフェース

```typescript
// packages/server/src/plugins/interfaces/base.ts

export type PluginType = 'data-source' | 'agent' | 'notification';

export interface PluginManifest {
  name: string;                    // 識別子（英数字-_のみ）
  displayName: string;             // 表示名
  version: string;                 // セマンティックバージョン
  type: PluginType;                // プラグインタイプ
  description?: string;
  author?: string;
  main: string;                    // エントリーポイント (例: "dist/index.js")
  configSchema?: ConfigSchema;     // 設定項目の定義
  requiredEnvVars?: string[];      // 必須環境変数
}

export interface ConfigSchema {
  [key: string]: ConfigField;
}

export interface ConfigField {
  type: 'string' | 'number' | 'boolean' | 'select';
  label: string;
  description?: string;
  required?: boolean;
  secret?: boolean;                // trueの場合、UIでマスク表示
  default?: string | number | boolean;
  options?: Array<{ value: string; label: string }>; // selectタイプ用
}

export interface ValidationResult {
  valid: boolean;
  errors?: string[];
}

export interface BasePlugin {
  readonly manifest: PluginManifest;
  initialize(config: Record<string, unknown>): Promise<void>;
  dispose(): Promise<void>;
  validateConfig?(config: Record<string, unknown>): Promise<ValidationResult>;
}
```

```typescript
// packages/server/src/plugins/manager.ts

export class PluginManager {
  private static instance: PluginManager;
  private loader: PluginLoader;
  private registry: PluginRegistry;
  private eventBus: EventBus;
  private currentAgentPlugin: AgentPlugin | null = null;

  static getInstance(pluginsDir?: string): PluginManager;

    // 3. 有効なプラグインを初期化
    // 4. 通知プラグインをEventBusに登録
    // 5. 現在のエージェントを設定から読み込み
  }

  // プラグイン一覧取得
  getPlugins(type?: PluginType): PluginState[];

  // エージェント管理
  getCurrentAgent(): AgentPlugin | null;
  async setCurrentAgent(name: string): Promise<void>;

  // 設定管理
  async updatePluginConfig(name: string, config: Record<string, unknown>): Promise<void>;
  async setPluginActive(name: string, isActive: boolean): Promise<void>;

  // イベント発行（Scheduler等から呼び出し）
  async publishEvent(event: NotificationEvent): Promise<void>;

  // DataSourceプラグインのデータ収集（既存互換）
  async executeDataSourcePlugins(params: FetchOptions): Promise<HealthDataInput[]> {
    const results: HealthDataInput[] = [];
    for (const plugin of this.registry.getDataSourcePlugins()) {
      const result = await plugin.fetchData(params);
      if (result.success) {
        results.push(...result.data);
      }
    }
    return this.resolveConflicts(results);
  }

  async dispose(): Promise<void>;
}
```

### 1.4 Agent統合詳細

#### 1.4.1 アーキテクチャ概要

Agent機能は抽象化レイヤーを通じて実装し、将来的に異なるAgent SDKへの差し替えを可能にします。
Skillsは`.claude/skills/`ディレクトリにSKILL.mdファイルとして定義し、Agent SDKが自動検出します。

```
health-manager-agent/
├── .claude/
│   └── skills/                     # Skills定義（ファイルベース）
│       └── get-health-data/
│           └── SKILL.md            # ヘルスデータ照会スキル
│
└── packages/server/src/agent/
    ├── index.ts                    # AgentService（Factoryパターン）
    ├── interfaces/
```

#### 1.4.4 Anthropic Agent SDK アダプタ実装

```typescript
// packages/server/src/agent/adapters/anthropic-adapter.ts

import { query, ToolInput, PermissionResult } from '@anthropic-ai/claude-agent-sdk';
import { AgentAdapter, GenerateReportParams, ReportContent } from '../interfaces/agent-adapter';
import { buildSystemPrompt } from '../prompts';
import { config } from '../../config';
import path from 'path';

export class AnthropicAgentAdapter implements AgentAdapter {
  readonly name = 'anthropic';
  private projectRoot: string;
  private serverBaseUrl: string;

  constructor() {
    this.projectRoot = path.resolve(__dirname, '../../../../..');
    // 自身のサーバーのベースURL（例: http://localhost:3000）
    this.serverBaseUrl = config.serverBaseUrl;
  }

  async initialize(): Promise<void> {
    // Agent SDKは状態を持たないため、初期化は不要
    // Skills は .claude/skills/ ディレクトリから自動検出される
  }

  /**
   * ツール使用の許可/拒否を判定するコールバック
   * 自身のサーバーへのリクエストのみを許可する
   */
  private canUseTool = async (
    toolName: string,
    input: ToolInput
  ): Promise<PermissionResult> => {
    // Bashツールの場合、curlコマンドで自身のサーバーへのリクエストのみ許可
    if (toolName === 'Bash') {
      const command = input.command as string;

      // curlコマンドかつ自身のサーバーへのリクエストのみ許可
      if (command.includes('curl')) {
        const isLocalRequest =
          command.includes(this.serverBaseUrl) ||
          command.includes('localhost:') ||
          command.includes('127.0.0.1:');

        if (isLocalRequest) {
          return { behavior: 'allow', updatedInput: input };
        }

        return {
          behavior: 'deny',
          message: `外部へのリクエストは許可されていません: ${command}`
        };
      }

      // curl以外のBashコマンドは拒否
      return {
        behavior: 'deny',
        message: `Bashコマンドは許可されていません: ${command}`
      };
    }

    // Skillツールは許可
    if (toolName === 'Skill') {
      return { behavior: 'allow', updatedInput: input };
    }

    // その他のツールは拒否
    return {
      behavior: 'deny',
      message: `ツール ${toolName} は許可されていません`
    };
  };

  async generateReport(params: GenerateReportParams): Promise<ReportContent> {
    const systemPrompt = buildSystemPrompt(
      params.reportType,
      params.customInstructions || []
    );

    const userPrompt = `${params.periodStart.toISOString()}から${params.periodEnd.toISOString()}までのヘルスデータを分析し、評価レポートを作成してください。`;

    let resultContent = '';

    // query() は async generator を返すため、for await...of でループ処理
    for await (const message of query({
      prompt: userPrompt,
      options: {
        cwd: this.projectRoot,
        systemPrompt: systemPrompt,
        settingSources: ['project'],  // .claude/skills/ からSkillsを読み込む
        model: 'claude-opus-4-5-20251101',  // Opus 4.5モデルを使用
        canUseTool: this.canUseTool,  // ツール使用の許可/拒否判定
      }
    })) {
      // アシスタントの応答を収集
      if (message.type === 'assistant' && message.message?.content) {
        for (const block of message.message.content) {
          if ('text' in block) {
            resultContent += block.text;
          }
        }
      }
    }

    return this.parseReportContent(resultContent);
  }

  private parseReportContent(response: string): ReportContent {
    // JSONブロックを抽出してパース
    const jsonMatch = response.match(/```json\n?([\s\S]*?)\n?```/);
    if (jsonMatch) {
      return JSON.parse(jsonMatch[1]) as ReportContent;
    }
    // JSONブロックがない場合は直接パースを試みる
    return JSON.parse(response) as ReportContent;
  }

  async dispose(): Promise<void> {
    // Agent SDKは状態を持たないため、クリーンアップ不要
  }
}
```

# get-health-data

保存されているヘルスデータを照会するスキルです。

## 使用方法

このスキルは `/get-health-data` コマンドで呼び出されます。

## サーバー情報

- ベースURL: `http://localhost:3000`
- すべてのAPIリクエストはこのサーバーに対して行います

## パラメータ

- **query_type**: クエリタイプ
  - `latest`: 最新のデータを取得
  - `range`: 期間を指定してデータを取得
  - `aggregate`: 集計データを取得
  - `trend`: トレンド分析データを取得

```typescript
import { CustomInstruction } from '../types';

export function buildSystemPrompt(
  reportType: 'on_fetch' | 'daily',
  customInstructions: CustomInstruction[]
): string {
  let prompt = `あなたはヘルスデータアナリストです。
ユーザーのヘルスデータを分析し、${reportType === 'daily' ? '日次' : '定期'}評価レポートを作成してください。

レポートには以下を含めてください：
- 全体的な健康状態のサマリー
- 各指標の現在値とトレンド
- リスクや注意点
- 改善のための推奨事項

レポートは以下のJSON形式で出力してください：
{
  "summary": "全体サマリー",
  "metrics": {
    "metric_name": { "value": 数値, "unit": "単位", "trend": "up|down|stable" }
  },
  "risks": ["リスク1", "リスク2"],
  "recommendations": ["推奨事項1", "推奨事項2"]
}
`;

  if (customInstructions.length > 0) {
    prompt += `\n\n## ユーザーからの特別な指示\n以下の点に特に注意してください：\n`;
    customInstructions
      .sort((a, b) => b.priority - a.priority)
      .forEach(inst => {
        prompt += `- ${inst.instruction}\n`;
      });
  }

  return prompt;
}
```

### 1.5 スケジューラ詳細

```typescript
// packages/server/src/scheduler/index.ts

import cron from 'node-cron';
import { PluginManager } from '../plugins/manager';
import { AgentService } from '../agent';
import { WebhookSender } from '../webhook/sender';
import { settingsRepository } from '../db/repositories/settings';

export class Scheduler {
  private dataCollectionJob: cron.ScheduledTask | null = null;
  private dailyReportJob: cron.ScheduledTask | null = null;
  private reminderJobs: Map<string, cron.ScheduledTask> = new Map();

  async start(): Promise<void> {
    const settings = await settingsRepository.getAll();

    // データ収集ジョブ
    const interval = settings.collection_interval || 3600;
    this.dataCollectionJob = cron.schedule(
      this.secondsToCron(interval),
      () => this.runDataCollection()
    );

    // 日次レポートジョブ（毎日0:05）
    this.dailyReportJob = cron.schedule('5 0 * * *', () => this.runDailyReport());

    // リマインダージョブ
    await this.setupReminderJobs();
  }

  private async runDataCollection(): Promise<void> {
    const pluginManager = PluginManager.getInstance();
    const agentService = AgentService.getInstance();
    const periodStart = this.getLastCollectionTime();
    const periodEnd = new Date();

    // 1. DataSourceプラグインからデータ取得
    const data = await pluginManager.executeDataSourcePlugins({
      startDate: periodStart,
      endDate: periodEnd
    });

    // 2. DBに保存
    await healthDataRepository.bulkInsert(data);

    // 3. 通知イベント発火（data:fetched）
    await pluginManager.publishEvent({
      type: 'data:fetched',
      timestamp: new Date(),
      payload: {
        sourceName: 'scheduler',
        recordCount: data.length,
        dataTypes: [...new Set(data.map(d => d.dataType))]
      }
    });

    // 4. 取得時レポート生成（AgentPluginを通じて実行）
    const content = await agentService.generateReport({
      reportType: 'on_fetch',
      periodStart,
      periodEnd
    });

    const report = await reportsRepository.insert({
      reportType: 'on_fetch',
      periodStart,
      periodEnd,
      content
    });

    // 5. 通知イベント発火（report:generated）
    await pluginManager.publishEvent({
      type: 'report:generated',
      timestamp: new Date(),
      payload: {
        reportId: report.id,
        reportType: 'on_fetch',
        content,
        periodStart,
        periodEnd
      }
    });
  }

  private async runDailyReport(): Promise<void> {
    const pluginManager = PluginManager.getInstance();
    const agentService = AgentService.getInstance();

    const periodEnd = new Date();
    periodEnd.setHours(0, 0, 0, 0);
    const periodStart = new Date(periodEnd);
    periodStart.setDate(periodStart.getDate() - 1);

    // 1. 日次レポート生成
    const content = await agentService.generateReport({
      reportType: 'daily',
      periodStart,
      periodEnd
    });

    const report = await reportsRepository.insert({
      reportType: 'daily',
      periodStart,
      periodEnd,
      content
    });

    // 2. 通知イベント発火（report:daily）
    await pluginManager.publishEvent({
      type: 'report:daily',
      timestamp: new Date(),
      payload: {
        reportId: report.id,
        reportType: 'daily',
        content,
        periodStart,
        periodEnd
      }
    });
  }

  private secondsToCron(seconds: number): string {
    if (seconds < 60) return `*/${seconds} * * * * *`;
    const minutes = Math.floor(seconds / 60);
    if (minutes < 60) return `*/${minutes} * * * *`;
    const hours = Math.floor(minutes / 60);
    return `0 */${hours} * * *`;
  }
}
```

## 3. 検証計画

### 3.1 単体テスト

| モジュール | テスト内容 |
|-----------|-----------|
| PluginLoader | ZIP展開、マニフェスト検証、エラーハンドリング |
| PluginManager | プラグイン読み込み、データ収集、競合解決 |
| HealthAgent | Skill実行、レポート生成、カスタム指示適用 |
| Scheduler | ジョブ登録、cron式生成、エラー時リトライ |
| API Routes | リクエスト検証、レスポンス形式、エラーレスポンス |

### 3.2 統合テスト

1. **データ収集フロー**
   - プラグインからデータ取得 → DB保存 → レポート生成 → Webhook送信

2. **プラグイン管理フロー**
   - ZIPアップロード → インストール → 設定 → 接続テスト → データ取得

3. **フロントエンド連携**
   - API呼び出し → データ表示 → CRUD操作

### 3.3 E2Eテスト

```bash
# サーバー起動
cd packages/server && npm run dev

# フロントエンド起動
cd packages/frontend && npm run dev

# テストシナリオ
1. ダッシュボードにアクセス
2. 手動でデータを追加
3. グラフに反映されることを確認
4. プラグインをインストール
5. 手動同期を実行
6. 取得データが表示されることを確認
7. レポートを生成
8. Webhook送信を確認
```
