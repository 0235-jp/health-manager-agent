# Claude Agent SDK Plugin

Claude Agent SDKを使用してヘルスデータを分析し、レポートを生成するAIエージェントプラグインです。

## 概要

- **タイプ**: Agent
- **プロバイダー**: Anthropic
- **バージョン**: 1.2.0

## 対応モデル

| モデル | モデルID |
|--------|----------|
| Claude Opus 4.5 | `claude-opus-4-5-20251101` |
| Claude Sonnet 4 | `claude-sonnet-4-20250514` |

## 機能

- ヘルスデータの分析と評価レポート生成
- カスタム指示に基づいた柔軟な分析
- 構造化されたJSON形式でのレポート出力
- **チャット機能**: ストリーミング対応のインタラクティブチャット（v1.1.0〜）
- **Web検索機能**: 健康に関する一般情報を検索・参照可能（v1.2.0〜）

### レポート形式

生成されるレポートには以下の情報が含まれます：

```json
{
  "summary": "全体的な健康状態のサマリー",
  "metrics": {
    "metric_name": {
      "value": 数値,
      "unit": "単位",
      "trend": "up|down|stable"
    }
  },
  "risks": ["リスク1", "リスク2"],
  "recommendations": ["推奨事項1", "推奨事項2"]
}
```

### チャット機能（v1.1.0〜）

ユーザーと対話形式で健康データについて相談できます。

- **ストリーミング対応**: リアルタイムでレスポンスを表示
- **セッション管理**: Claude Agent SDKのセッション機能を使用して会話を継続
- **スキル連携**: `get-health-data`スキルを使用してデータを自動取得

## 設定

### プラグイン設定（UI）

| 設定項目 | 型 | 必須 | デフォルト | 説明 |
|----------|-----|------|----------|------|
| `model` | select | No | `claude-opus-4-5-20251101` | 使用するClaudeモデル |
| `apiKey` | string | No | - | Anthropic API Key |
| `baseUrl` | string | No | - | カスタムエンドポイント（通常は空欄でOK） |

### 環境変数（オプション）

| 変数名 | 必須 | 説明 |
|--------|------|------|
| `SERVER_BASE_URL` | No | サーバーのベースURL（デフォルト: `http://localhost:3001`） |

## インストール

1. `plugins/claude-agent-sdk` ディレクトリに配置
2. 依存関係をインストール:
   ```bash
   cd plugins/claude-agent-sdk
   npm install
   ```
3. ビルド:
   ```bash
   npm run build
   ```
4. プラグイン管理画面からインストール
5. 設定画面でAPI Keyを入力

## 使用方法

1. プラグイン管理画面で「Claude Agent SDK」を有効化
2. 設定画面でAPI Keyを入力
3. モデルを選択（設定で変更可能）
4. エージェントプラグインとして選択されると、以下の機能で使用されます：
   - **レポート生成**: スケジューラーによる定期レポート生成や手動分析
   - **チャット**: 左メニューの「チャット」から健康データについて相談

## セキュリティ

このプラグインは以下のセキュリティ制限を実装しています：

- **許可されるツール**: `Bash`（ローカルサーバーへのcurlのみ）、`Skill`、`WebSearch`、`WebFetch`
- **外部リクエスト**: Bash経由はブロック（ローカルサーバーへのリクエストのみ許可）、Web検索は許可
- **ファイルアクセス**: 制限あり
